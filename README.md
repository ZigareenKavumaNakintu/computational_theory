# Computational Theory 

## Description 
This repository contains the learning outcomes and knowledge obtained from the Computational Theory Module. The project is written in Python and Problems are presented in Jupyter Notebooks.

The purpose of this repository is to demonstrate the application of computational theory through problem-solving and Python implementations.

## Problems
Problems are contained in **problems.ipynb**. Each problem includes an explanation of the task, the approach to solve it and relevant python implementation, illustrations(flow charts) and the resulting outputs.


## Getting Started 

### Dependencies
The following are required to run the project:
- Python 3.14 or later
- Jupyter NotebookS
- The Python packages listed in `requirements.txt`

### Installing 
- Make sure you have python installed.
- Clone the repository


### Running the Notebook 
In order to run to run 'problems.ipynb' you can follow these steps:
1. Clone the repository: 

    `git clone https://github.com/ZigareenKavumaNakintu/computational_theory.git`

2. Navigate to the project directory: 

    `cd computational_theory`

3. Install the required Python packages:

    `pip install -r requirements.txt`

4. To run the notebook: 

    `jupyter notebook problems.ipynb`

## Guidance

For additional guidance on the problems, please refer to the [GitHub Issues](https://github.com/ZigareenKavumaNakintu/computational_theory/issues). Each relevant issue contains guidance and information to help with the corresponding problem.
